# نبراس · دليل التشغيل خطوة بخطوة

نسخة تجريبية من منصة «نبراس»: لعبة تشخيص، مسار تعلّم، معلم افتراضي (Claude)، وصفحة للأهالي.
المحتوى الرياضي مسودة بانتظار مراجعة معلم رياضيات.

---

## شو في بالملفات؟

```
nibras-site/
├── index.html                 الصفحة الرئيسية (بتحمّل كل الملفات)
├── assets/
│   ├── css/styles.css         التصميم والألوان
│   ├── img/favicon.svg        أيقونة الموقع
│   └── js/
│       ├── config.js          ⚙️ الإعدادات — الملف الوحيد اللي بتعدّليه
│       ├── data.js            المحتوى: المستويات والمهارات والأسئلة ومكتبة الأخطاء
│       ├── engine.js          محرك التصحيح (بيتحقق من الجواب حسابياً)
│       ├── backend.js         الحسابات وقاعدة البيانات والذكاء الاصطناعي
│       └── app.js             الصفحات واللعبة والشات وصفحة الأهالي
└── supabase/
    ├── migrations/0001_nibras.sql   قاعدة البيانات (بتنشغل مرة وحدة)
    ├── functions/nibras-ai/index.ts الخادم الصغير اللي بيحكي مع Claude
    └── config.toml                  إعداد الدالة (للـ CLI بس)
```

### كيف الأجزاء مربوطة ببعض

```
المتصفح (GitHub Pages)
   │  تسجيل دخول + حفظ التقدّم
   ├──────────────► Supabase (Auth + قاعدة بيانات Postgres)
   │  سؤال للذكاء الاصطناعي + رمز الدخول
   └──────────────► Edge Function «nibras-ai» ──► Claude API
                     (مفتاح Claude مخزّن هون بس، مش بالمتصفح)
```

### وضعين للتشغيل

| الوضع | متى | شو بيشتغل |
|---|---|---|
| تجريبي محلي | `config.js` فاضي | الحسابات على نفس الجهاز، اللعبة والمسار وصفحة الأهالي. **بدون** ذكاء اصطناعي |
| حقيقي | `config.js` معبّى | حسابات حقيقية من أي جهاز + الشات + تقرير نبراس + تحليل الأجوبة الغلط |

## قبل ما تبلّشي: 3 حسابات

1. **GitHub**: https://github.com (مجاني) — لنشر الموقع.
2. **Supabase**: https://supabase.com (الخطة المجانية) — للحسابات وقاعدة البيانات والدالة.
3. **Claude Console**: https://platform.claude.com — لمفتاح Claude API والرصيد.

> ⚠️ قاعدة أمان: **مفتاح Claude** و **مفتاح Supabase السري** (`secret` أو `service_role`) ما بينحطّوا أبداً بأي ملف بالموقع ولا على GitHub.
> بس المفتاح «العام» (`publishable` أو `anon`) بينحط بـ `config.js`.

## الخطوة 0 (اختياري): جرّبي الموقع على جهازك

افتحي `index.html` مباشرة بالمتصفح، أو شغّلي من داخل المجلد:

```
python3 -m http.server 8000
```

وافتحي http://localhost:8000 — رح يشتغل «وضع تجريبي محلي».

---

## الخطوة 1: مشروع Supabase

1. ادخلي supabase.com ← **New project**.
2. اختاري اسم (مثلاً `nibras`)، كلمة سر لقاعدة البيانات (احفظيها عندك)، ومنطقة قريبة.
3. استني لحد ما يجهز المشروع.

## الخطوة 2: قاعدة البيانات

1. من القائمة الجانبية: **SQL Editor** ← **New query**.
2. افتحي ملف `supabase/migrations/0001_nibras.sql`، انسخي كل محتواه والصقيه.
3. اضغطي **Run**. لازم يطلع «Success».
4. للتأكد: **Table Editor** ← لازم تشوفي الجداول: `profiles`, `progress`, `links`, `ai_usage`.

> الملف بيعمل كمان «Row Level Security»: كل طالب بيشوف بياناته بس، وولي الأمر بيشوف بس الأولاد المربوطين معه.

## الخطوة 3: إعدادات تسجيل الدخول (مهمة جداً)

1. **Authentication** ← **Sign In / Providers** (أو Providers) ← **Email**.
2. تأكدي إنه **Email** مفعّل.
3. **طفّي «Confirm email»** واحفظي.
   - السبب: خدمة الإيميل الافتراضية بـ Supabase بتبعت بس لإيميلات أعضاء فريق المشروع، فبدون هالخطوة الطلاب ما رح يقدروا يعملوا حسابات.
4. **Authentication** ← **URL Configuration** ← **Site URL**: حطي رابط الموقع بعد ما تنشريه (الخطوة 7).

## الخطوة 4: مفتاح Claude API

1. ادخلي https://platform.claude.com ← **API Keys** ← **Create Key**.
2. سمّيه `nibras` وانسخيه فوراً (بيظهر مرة وحدة بس). خليه بمكان آمن، ولا تبعتيه لحدا.
3. **الرصيد:** شوفي «متى أدفع؟» تحت.

## الخطوة 5: الـ Edge Function (الخادم اللي بيحكي مع Claude)

### الطريقة الأسهل: من لوحة Supabase

1. **Edge Functions** ← **Deploy a new function** ← **Via Editor**.
2. اسم الدالة لازم يكون بالضبط: `nibras-ai`
3. امسحي الكود الموجود، والصقي كل محتوى `supabase/functions/nibras-ai/index.ts`.
4. **Deploy function**.
5. افتحي الدالة ← الإعدادات/التفاصيل ← طفّي **Enforce JWT Verification** (أو «Verify JWT») واحفظي.
   - الدالة بتتحقق من دخول المستخدم بنفسها، فهاد آمن.
   - إذا ما لقيتي الخيار، استخدمي طريقة الـ CLI تحت.

### إضافة الأسرار (Secrets)

**Edge Functions** ← **Secrets** (Edge Function Secrets) ← أضيفي:

| Key | Value | لازم؟ |
|---|---|---|
| `ANTHROPIC_API_KEY` | مفتاح Claude من الخطوة 4 | ✅ لازم |
| `NIBRAS_DAILY_LIMIT` | عدد رسائل الذكاء الاصطناعي لكل مستخدم باليوم (الافتراضي 60) | اختياري |
| `NIBRAS_ALLOWED_ORIGINS` | رابط موقعك، مثلاً `https://USERNAME.github.io` | اختياري (أأمن) |
| `NIBRAS_MODEL_MAIN` | الموديل للشات والتقرير (الافتراضي `claude-haiku-4-5-20251001`) | اختياري |
| `NIBRAS_MODEL_QUICK` | الموديل لتحليل الأجوبة (الافتراضي نفسه) | اختياري |

> `SUPABASE_URL` والمفاتيح الداخلية موجودين تلقائياً، ما بتضيفيهم.

### طريقة بديلة: Supabase CLI (من الكمبيوتر)

```
npx supabase login
npx supabase link --project-ref <PROJECT_REF>
npx supabase secrets set ANTHROPIC_API_KEY=sk-ant-...
npx supabase functions deploy nibras-ai --no-verify-jwt
```

`<PROJECT_REF>` هو الجزء الأول من رابط المشروع (`https://<PROJECT_REF>.supabase.co`).

## الخطوة 6: عبّي `config.js`

من Supabase: **Project Settings** ← **API Keys** (أو زر **Connect**):

```js
window.NIBRAS_CONFIG = {
  SUPABASE_URL: "https://xxxxxxxx.supabase.co",
  SUPABASE_KEY: "sb_publishable_xxxxxxxx",   // أو مفتاح anon القديم
  AI_FUNCTION: "nibras-ai",
  AI_ENABLED: true,
  PHONE_EMAIL_DOMAIN: ""
};
```

## الخطوة 7: النشر على GitHub Pages

1. GitHub ← **New repository** ← اسم مثل `nibras` ← **Public** (Pages مجاني للمستودعات العامة).
2. **Add file** ← **Upload files** ← اسحبي **محتوى** المجلد (مش المجلد نفسه): `index.html` و `assets` و `supabase` و `README.md` و `.nojekyll`.
3. **Commit changes**.
4. **Settings** ← **Pages** ← Source: **Deploy from a branch** ← Branch: `main` ← Folder: `/ (root)` ← **Save**.
5. بعد دقيقة أو اثنتين، الرابط بيصير: `https://USERNAME.github.io/nibras/`
6. ارجعي لـ Supabase وحطي هالرابط بـ **Site URL** (الخطوة 3).

> المستودع عام، يعني الكود ظاهر للناس. هاد عادي لأنه ما فيه أي مفتاح سري.

## الخطوة 8: جرّبي كل إشي

| الجزء | كيف تجرّبيه | لازم يصير |
|---|---|---|
| حساب طالب | دخول الطلاب ← حساب جديد | بيوصل «أهلاً …!» وبينضاف صف بجدول `profiles` |
| اللعبة | ابدأ اللعبة، جاوبي كم سؤال غلط | صفحة النتيجة + «تقرير نبراس» |
| تحليل الأجوبة | بتفاصيل التشخيص (للمعلم) | «الطريقة: تحليل نبراس (AI)» عند بعض الأجوبة |
| الشات | اسأل نبراس | رد من نبراس |
| الحفظ | سكّري المتصفح وارجعي من جهاز ثاني | نفس التقدّم |
| الأهالي | انسخي رمز الربط من «حسابي» ← حساب ولي أمر ← اربط | بطاقة الطالب والتقرير والرسائل |

### إذا في مشكلة

| الرسالة | الحل |
|---|---|
| «الحساب انعمل بس بيستنى تأكيد الإيميل» | ما طفّيتي «Confirm email» (الخطوة 3) |
| «ما قدرنا نجيب بيانات الحساب…» | ما انشغّل ملف SQL (الخطوة 2) |
| «نبراس لسا مش مجهّز على الخادم» | `ANTHROPIC_API_KEY` ناقص أو غلط، أو الدالة مش منشورة باسم `nibras-ai` |
| «رصيد الذكاء الاصطناعي خلص» | اشتري رصيد من Claude Console |
| «لازم تسجّل دخول من جديد» بالشات | غالباً JWT verification لسا مفعّل، طفّيه (الخطوة 5) |
| «الإيميل مش مقبول» عند التسجيل برقم جوال | سجّلي بالإيميل بدل الرقم (شوف الملاحظة تحت) |
| «في محاولات كثير هلأ» | Supabase بيحدّد عدد التسجيلات من نفس الشبكة. **Authentication ← Rate Limits** |

لمعرفة الخطأ بالضبط: **Edge Functions ← nibras-ai ← Logs**، أو Console بالمتصفح (F12).

## متى أدفع؟ (رصيد Claude)

- **Supabase (الخطة المجانية) و GitHub Pages: $0.**
- **Claude API:** بالدفع المسبق (رصيد). اعملي الحساب والمفتاح بأي وقت، بس **اشتري الرصيد بعد ما تخلّصي الخطوة 5 وقبل ما تجرّبي الشات مباشرة**.
- المكان: **Claude Console ← Settings ← Billing ← Buy credits**.
- **طفّي Auto-reload** (الشحن التلقائي) عشان ما ينسحب من البطاقة لحاله.
- الرصيد **ما بيرجع** (non-refundable) و **بينتهي بعد سنة** من الشراء، فاشتري مبلغ صغير.
- **تقدير تقريبي مش مؤكد:** كل رسالة شات بتبعت تعليمات نبراس + بيانات المسار (تقريباً 10 آلاف حرف) — مع Claude Haiku 4.5 ($1 لكل مليون توكن إدخال، $5 لكل مليون توكن إخراج) هاد غالباً أقل من سنت للرسالة. لـ 5–10 طلاب بتجربة قصيرة، مبلغ صغير (كم دولار) غالباً بيكفي. الرقم الحقيقي بتشوفيه بـ **Usage** بالـ Console بعد أول تجربة.

## ملاحظات مهمة

- **الدخول برقم الجوال** ما بيبعت SMS: الموقع بيحوّل الرقم لإيميل مخفي. ممكن Supabase يرفض هالإيميل (لا أملك معلومة مؤكدة إنه رح يقبله بكل المشاريع). إذا صار هيك، استخدموا الإيميل، أو حطي بـ `PHONE_EMAIL_DOMAIN` دومين بتملكيه.
- **رسائل الأهالي** بتظهر بصفحة الأهالي بس (محاكاة). الإرسال الحقيقي بالإيميل/SMS بيحتاج خدمة إرسال (مرحلة جاية).
- **الخطة المجانية لـ Supabase** بتوقّف المشروع إذا ما انستخدم أسبوع. قبل العرض بيوم افتحي الموقع، وإذا موقوف: لوحة Supabase ← **Restore**.
- **الخصوصية:** الطلاب قاصرين — اسم مستعار بس، بدون اسم حقيقي أو صورة. الإيميل/الرقم تبع الطالب مش مخزّن بجدول `profiles` (بس بنظام الدخول).
- **تعديل المحتوى** (أسئلة، مهارات): `assets/js/data.js`، وبعد أي تعديل ارفعي الملف على GitHub من جديد.
- النسخة تجريبية للجنة والدكاترة، مش منصة جاهزة للاستخدام الواسع.
